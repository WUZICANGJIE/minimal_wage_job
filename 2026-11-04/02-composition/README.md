# 中阶版：招聘总量与兼职构成

保留上次发表的主比较：2025年11月，10月发效20县对12月以后发效14县，排除11月发效13县。新增的问题是：兼职的相对变化，伴随着招聘总量变化，还是招聘构成变化？这是课程内的增量，不是新识别方法，也不声称首次研究两类招聘。

## 结果

先计算各县11月同比减1—9月平均同比，再比较早组减晚组，各县等权。同比为对数差×100；下面除比率外均为该指标的差。

| 指标 | 点估计 | Welch 95%区间 |
|---|---:|---:|
| 兼职 | −1.56 | [−7.93, 4.82] |
| 非兼职 | 0.67 | [−3.02, 4.37] |
| 总量 | −0.15 | [−4.15, 3.85] |
| 相对指标（兼职−非兼职） | −2.23 | [−8.05, 3.59] |
| 兼职比率（百分点） | −0.51 | [−1.85, 0.82] |

主兼职负方向单侧p=0.310，相对指标p=0.220。所有区间均含零，不能确认负的相对差，也不能排除总量收缩。1—7月基准的兼职差为−2.18、相对差−2.89，同样不显著。比率和相对指标来自相同原系列，但经过非线性变换、差分及平均后并不等价；不把两者当独立验证。

## 模型与创新程度

使用Acemoglu and Autor（2011）式(2)—(6)的CES两类投入框架，借用部分已核对本文pp.1103—1105（PDF物理pp.61—63）。本报告另加递减收益和每名新录用者的总费用，明确设为“期间工资＋招聘经费”；新部门没有既有员工，录用数作为当期投入，招聘枠通过固定充足率转换。这些都是课堂简化，不是原作者的招聘模型。

相对成本上升会降低兼职相对需求；非兼职自身可因替代而增加，也可因规模收缩而减少。因此非兼职不是未处理对照，也不等于正社员。公式、边界及企业模型到县集计的附加假设见 `methods.md`。63组参数用于数学检算，全部是假定值，没有估计替代弹性。

中等难度来自两类投入的成本最小化和规模选择，实证仍是县级均值差，不需要复杂DID、IV或结构估计。

## 文件与复现

- `slides.md`、`slides.pdf`、`slides.html`：10页日文发表，涵盖课题3与4。
- `analysis.py`、已执行的 `analysis.ipynb`：真实数据、模型检查、结果和图。
- `build_notebook.py`：生成并执行notebook；使用当前Python，只写本目录的kernel描述。
- `tests/`、`check_delivery.py`、`verification*.json`：测试及交付检查。
- `results/`：县级中间结果、主估计和敏感性CSV；`assets/`：图和日文字体。
- `sources.md`、`evidence/`：来源、官方政策交叉核查及实际证据。

在本目录、装好 `requirements.txt` 的隔离Python环境内运行：

```bash
python analysis.py
python -m unittest discover -s tests -v
python build_notebook.py
CHROME_PATH=/usr/bin/chromium npx --yes @marp-team/marp-cli@4.5.1 slides.md --no-config --html --allow-local-files --pdf -o slides.pdf
npx --yes @marp-team/marp-cli@4.5.1 slides.md --no-config --html -o slides.html
python check_delivery.py
```

统计从项目根目录 `data/raw/` 读取两份Excel，不依赖旧结果CSV、不改原数据。已有本地字体时统计与notebook可离线运行；生成slides还需Node/npm和Chromium，首次取得Marp需要网络。HTML需连同相对路径assets一起移动。更换机器后用自己的Python，勿依赖本次临时venv路径。
