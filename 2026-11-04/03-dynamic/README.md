# 高创新版：未来工资与招聘的跨期配置

本目录同时交付课题3（模型、假说）和课题4（真实数据检验）的可运行初稿。以2026-11-04发表为文件日期；文献访问日期和执行时间保留真实日志，不伪装为未来日期。保留10月28日已发表的主比较，并未把研究换成另一个群体或新的识别设计。

## 结果

- **2025年11月part主差**（10月发效20县−12月以后14县，县等权、1—9月县内基准）：−1.5554104519904133，Welch 95%区间[−7.933877955930516, 4.823057051949689]；负向单侧p=.310082，双侧p=.620164。方向符合原H1，但证据不足；不等于证明无效。
- 1—7月基准：−2.1798208529984056，95%区间[−8.847659583025631, 4.48801787702882]。不是无预期的保证。
- 补充的后续路径形状：2026年4—6月早晚差减2025年11月早晚差为−.671188，95%区间[−6.158003,4.815627]。点估计未显示相对补充，但精度低；**该探索性窗口两组都已处理，仅描述，不识别catch-up或模型机制**。
- 164个原始月份（2013-01—2026-08）、47县、全国总计、part+nonpart=total、年度表头均通过；分析面板47×44=2,068。2024年政策额和日期与另一官方PDF逐县47项全匹配。
- 两期模型两期都选招聘。200组假定参数的KKT和独立数值优化通过，其中134内点的导数中心差分误差最大约1.20e−10；这验证数学，不验证机制。

## 本方案真正增加的经济问题

原发表主要问共同月份的早晚招聘差；本案新增“**企业现在招人，还是承受未来工资和招聘成本、以后再招？**”。在Hamermesh动态劳动需求/gross调整成本基础上，明确写出两期招聘选择；不是给一期利润函数多加时间下标，也不是把原模型改名为DMP。

内点、同样需求/离职/充足率等条件下：未来工资预期变高会通过持续雇佣和凸招聘成本影响当前招聘；当前工资较高会减少当前招聘，并在第二期产生相对于另一路径的补充。后者**不是第二期招聘一定高于第一期，不是就业恢复**。κ=0或员工完全不跨期存续时，本模型的内点预期效应为零。现实中晚组未来涨幅较大，简单的早负晚正符号没有无条件保证。所有参数是假定值，不估计、不过度称为校准。

先行文献已研究预期与求人动态（Kudlyak等），制度报告也比较了2025年的早晚募集工资（Nowcast/连合）。本案是可解释的课程扩展，不声称首创。数学限于凹二次目标、2×2线性方程和四个非负边界候选；实证是透明均值差和基础OLS，难度不超过普通研究生。

## 必须带进发表的限制

1. 晚组14县在12月已7个全月+1个部分处理，未处理只6；1—2月只2；3月无全月未处理；4月全处理。不能把后续路径包装成一直有未处理对照的DID。
2. 公表、答申、法定发效、实际涨薪与招聘计划不是同日。1—7月仅减少8—9月公表后的基准污染，不能消除全部预期。
3. 同比也减去年份2024的政策影响（德岛11月1日等）；同一2025分组在2024的比较不是无政策placebo。
4. 晚组平均涨幅7.78%、早组6.39%，水平与城市结构也不同。涨幅控制不能制造外生时点或充分重叠。
5. 模型$v$是企业名额水准，数据$y$是受理地县集计的对数同比。需求、离职、充足、渠道与企业构成稳定等桥接假设不被观察；真实数据只查时序和差异，不能识别κ、q、r、预期形成或最低工资因果效应。
6. 两期末值设0是课堂简化，绝不把末期模拟当长期均衡。没有流动性约束，所以“在籍工资节省让企业有钱招聘”不是本模型推出的渠道。
