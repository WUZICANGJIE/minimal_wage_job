# 20頁版の視覚確認

対象：slides.pdf と slides.html。PDFから1280×720のPNGを20枚生成し、4列×5行の一覧と、全20頁のフルサイズ画像を確認した。発表時間の実測ではない。

| 頁 | 確認した内容 | 最終確認 |
|---|---|---|
| 1–4 | 表紙、政策群、統計定義、前年同月比、先行研究表 | 文字切れ・重なりなし。文献表と補足は可読 |
| 5–8 | 賃金制約、利潤、FOC・二階条件、解・比較静学 | 分数・指数・添字・微分記号を確認。欠字箱・TeX漏出なし |
| 9–11 | 人数の数値例、補充採用式、公的経路、離職の例 | 数字・単位・仮定値の表示が読める。Vの定義も正文に追加 |
| 12–14 | 仮説、東京都の実際の計算、早期−後期の表と差分 | 矢印の条件、負数の引き算、Deltaのハットを確認 |
| 15–18 | 月次推移、県散布、Welch区間、基準感度 | 全軸・凡例・点/線・区間数値と説明が表示範囲内 |
| 19–20 | 結論・限界、書誌・版・リンク | 長い題名を含め、文字切れ・重なりなし |

初回レンダリング後、HTMLブロック内の行内数式が原文のまま出る箇所を6・10・14・16頁で検出した。Markdownとして解析される段落に直し、再レンダリング。最終版は `.katex-error` 0、可視のTeX漏出0、全20頁の横/縦スクロール範囲内、画像欠損0、本文と出典の重なり0。独立した数式は30pxを維持した。これらは verify_artifacts.py の実行結果でも検査している。

実データの図は描き直さず、そのまま使用した。説明例のみ既存関数で計算し、仮定と結果を teaching_examples.json に保存。原統計CSV・analysis.py・raw ExcelのSHA-256は不変。別出力先への再計算でも六つのCSVは逐字節一致した。

再利用する編集手順：slides.mdを唯一の正文源とし、講稿は非表示commentから出力する。数式を足したらDOMで可視TeXと境界を検査し、PDF全頁も視覚確認する。ページ数だけを更新して合格扱いにはしない。統計結果は別ディレクトリに再現し、元の出力と比較する。
