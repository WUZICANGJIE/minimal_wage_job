# 最低工资生效时间与兼职招聘

京都大学微观经济学小组研究：2025年度最低工资生效较早和较晚的县，兼职新规求人数的变化是否不同？

## 资料与发表

- [materials/](materials/README.md)：论文与参考资料。
- [2026-10-21/](2026-10-21/README.md)：选题发表，含日文 slides、PDF 和 HTML。

以后每次课新建 `YYYY-MM-DD/` 文件夹；共用资料统一放在 `materials/`。

## 第一次使用

只看资料，直接打开PDF即可。要一起编辑，先用自己的GitHub账号接受邀请，再把仓库链接和下面这段话交给能操作电脑的Agent：

> 请按照本仓库README帮我配置协作环境。我不熟悉电脑操作，请实际完成下载和PDF导出检查。需要我登录或批准安装时，简短告诉我怎么做。先不要上传修改。

### 给Agent的setup说明

1. 检查用户电脑的系统、Git、Node.js/npm、Chrome或Edge及日文字体。优先使用已有软件，缺少的经用户同意后从官方来源安装。
2. 用用户自己的账号获取仓库。已有本地副本时，先检查未提交修改，不覆盖用户文件。登录由用户本人完成，不索要密码或验证码。
3. 阅读对应日期的README，编辑 `slides.md`。按其中命令在忽略目录 `.cache/setup-check/` 试着生成PDF和HTML，不覆盖现有文件。
4. 打开结果，检查页数、日文显示和排版，并测试HTML翻页。完成后告诉用户保存位置；无法完成的部分直接说明。

## 平时协作

修改前先获取最新版本；编辑Markdown后重新导出PDF和HTML。内容确认后再让Agent提交、上传；多人同时改一份文件时先分工，有冲突不要强行覆盖。

仓库内说明用中文，发表用的slides保持日文。论文全文仅供组内学习，勿擅自公开。
