## 第一次使用

仓库已公开，阅读、下载和本地编辑不需要邀请或登录。把下面整段交给能操作电脑的Agent即可：

> 请打开仓库 https://github.com/WUZICANGJIE/minimal_wage_job ，按照README帮我配置协作环境。我不熟悉电脑操作，请实际完成下载，并在临时目录导出、打开PDF和HTML检查。优先使用已有软件，需要安装或登录时先征求我的同意。不要修改现有资料，也不要提交或上传修改。

### 给Agent的setup说明

1. 检查用户电脑的系统、Git、Node.js/npm、Chrome或Edge及日文字体。优先使用已有软件，缺少的经用户同意后从官方来源安装。
2. 直接克隆公开仓库；已有本地副本时，先检查未提交修改，不覆盖用户文件。仅在之后需要上传时使用用户自己的GitHub账号，登录由本人完成，不索要密码或验证码。
3. 阅读对应日期的README，不改动 `slides.md`。在仓库根目录新建 `.cache/setup-check/`，按导出命令将PDF和HTML的输出路径改到该目录，不覆盖现有文件。
4. 打开结果，检查页数、日文显示和排版，并测试HTML翻页。完成后告诉用户保存位置；无法完成的部分直接说明。

## 平时协作

修改前先获取最新版本；编辑Markdown后重新导出PDF和HTML。内容确认后再让Agent提交、上传。直接上传需要协作者权限；没有权限时可用自己的账号fork并发起Pull request。多人同时改一份文件时先分工，有冲突不要强行覆盖。

仓库内说明用中文，发表用的slides保持日文。论文版权归作者及出版方，引用请注明来源，转载全文须确认授权。
